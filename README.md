# Vroomer Site

A metal box 90s kid website for showcasing photography, with basic support for either showing blog posts - or social media feed(s).

## Getting Started

It is assumed that you already have VSCode installed. If not, see the [VSCode](VSCode IDE Configuration) section below.

1. Download VSCode if you don't already have it. (*The addons/extensions that will help you the most will be listed below.*)

- Either clone the repo locally, or download a .zip of the master branch.
